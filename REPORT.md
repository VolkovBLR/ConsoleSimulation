# Отчёт. ИЗ №1 «Архитектура компьютера и ОС»

**Исполнитель:** Волков Давид Леонидович, группа 257 
**Вариант:** 20. Автогонки

## Условие

Консольная имитация гонки на кольцевой клетчатой трассе: команды по две
машины, ходы по правилам Пудова (лидер 1–4, вторая до хода лидера+2,
остальные до хода предыдущей+1). Вбок внутрь стоит 1, наружу — 3.
Нулевой ход → сход после раунда. Опционально круговые премии и снятие
отставших на круг.

## Сценарий → процессы

Программа **последовательная**: акторы — не потоки ОС, а структуры и
функции, вызываемые по очереди.

| сущность | отображение |
|---|---|
| судья | `race_run`, `after_round`, `sort_order` |
| водитель / машина | `struct Car`, `do_move`, стратегия greedy/random |
| трасса | `occ[lane][sec]`, длина круга `sectors` |
| ход | поиск маршрута `dfs` с бюджетом клеток |
| зритель | вывод событий через `write(2)` на stdout и в лог |

Цикл: раунд → машины в текущем порядке → пересчёт мест → проверка
финиша/схода/лимита раундов.

## Интерфейс

CLI (`--lanes`, `--sectors`, `--laps`, `--teams`, `--cars`, `--strategy`,
`--bonus`, `--lapping`, `--max-rounds`, `--seed`, `--delay`, `--log`,
`--start`, `--interactive`).  
События: порядок хода, лимит, маршрут, смена дорожки, блок, нулевой ход,
круг, премия, сход, финиш, карта, классификация.

## Запуск и завершение

- норма: все финишировали/сошли, или `--max-rounds`;
- ошибка параметров: код 1;
- `SIGINT`/`SIGTERM`: `stop_flag`, итог печатается, лог закрывается.

Примеры см. `README.md`. Журнал по умолчанию `race.log`.

## Результаты прогона

После `make && ./autogonki --seed 1 --laps 2` вставить фрагмент
классификации из `race.log`.
